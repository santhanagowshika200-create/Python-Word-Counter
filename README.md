# Python Word Counter

## Description
This project is a Word Counter application developed using Python. It reads a text file and counts the total number of words, characters, and lines present in the file.

It helps users analyze text easily using Python file handling concepts.

## Features
- Reads text from a file.
- Counts total words.
- Counts total characters.
- Counts total lines.
- Displays the results clearly.
- Handles file not found errors.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Keep the text file in the project folder.
4. Open the terminal.
5. Run the following command:

```bash
python word_counter.py
```

## Sample Output

```text
Enter file name: sample.txt

Total Words: 50
Total Characters: 250
Total Lines: 10
```
